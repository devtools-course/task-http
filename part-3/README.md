# HTTP

> Part 3. Redirections

You are to create a script `part-3.sh` which sends a request to the server and collects all redirections.

The script must print all URLs that are encountered when resolving the server location.

**Synopsis:**
```cmd
./part-3.sh <URL>
```

**Output:**
```cmd
http://google.de/
http://www.google.de/
http://www.google.com/
```
## Error handling

Is not needed. We guarantee the correctness of the input data.
